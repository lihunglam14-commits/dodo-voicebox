## 1. 產品定位（官方講法，一字不改咁搬得上網站）
> **DoDo VoiceBox** 係一部**粵語優先嘅 AI 語音陪伴裝置**，為香港長者而設，
> 針對孤獨感同社交孤立。佢係**陪伴，唔係醫療**（companion, not clinical）：
> 只觀察、唔診斷、唔自主行動；有需要時，喺**長者同意**之下，將關注訊號
> 交畀**人**（家人照顧者）跟進。

**五大硬原則**（產品憲法，適合做網站 trust page）：
1. 安全路徑永遠優先於一切功能
2. 只觀察，永不自動行動、永不自動診斷
3. 永不利用長者嘅依附感（明文排除「用得耐」做成功指標）
4. 照顧者披露必須經同意，預設拒絕（fail-safe deny）
5. 絕不自主採取醫療或緊急行動

## 4. 網站好可能未講、但值得講嘅嘢（差異化清單）
1. **「核實先講，過期寧靜」** —— 每個福利數字有人手核實紀錄＋到期日；過期自動收聲
2. **「唔靠你用得耐」** —— 明文排除 engagement 做成功指標（AI 陪伴產品極罕見）
3. **五大原則全文**（§1）—— 誠實係產品功能
4. **雙層數字設計嘅道理** —— 長者唔使記數字，屋企人攞精確資料辦事
5. **私隱工程實話**：日誌無原文、30 日限期、同意先披露
6. **無廣告**
7. **香港福利知識深耕**：長生津/生果金/傷殘津貼/醫療券/兩蚊優惠/院舍券 —— 全部官方來源

## 5. 講法治理（THE LAW —— 文案逐句對照本表）

### ✅ 可以講
| Claim | 依據 |
|---|---|
| 粵語優先 AI 語音陪伴，為香港長者而設 | §1 |
| 福利資訊由創辦人逐條對照政府官方網站核實，附核實日期 | §3，B3 紀錄 |
| 資訊過期會自動停止播報（寧靜好過講錯） | fail-closed＋review_by |
| 對長者講大約數，精確數字同申請程序交畀照顧者 | ε0 pivot |
| 唔以使用時長做成功指標；無廣告 | 產品憲法 |
| 對話日誌不儲存原文；資料有保留期限 | §3 私隱工程 |
| 關注訊號**經長者同意**先會話畀家人知，由人決定跟進 | invariant 4 |

### ⚠️ 小心講（措辭有規定）
| 意思 | 准用措辭 | 禁用措辭 |
|---|---|---|
| 照顧者知情 | 「喺長者同意下，同家人分享關注」 | monitor／監察／追蹤／睇住 |
| 產品類別 | 陪伴、傾偈、關心 | 照護、護理、看護 |
| 團隊 | 香港團隊、香港設計 | 數據留喺香港（**而家係假**） |

### ⛔ 唔准講（連暗示都唔准）
| 禁區 | 點解 |
|---|---|
| 任何醫療/診斷/健康監測/病症偵測字眼（抑鬱、認知障礙、跌倒偵測…） | 醫療器械分類風險；法律意見未返；invariant 2/5 |
| 緊急求助/救命/平安鐘類比 | 硬件無此功能；invariant 5 |
| 「數據全本地/不出香港」 | 現時經美國雲端處理 |
| 用戶見證/長者使用相/「N 位長者用緊」 | 零真實用戶 |
| 價格/發售日/預購/落單 | pilot 法律文件未齊 |
| 免提/喚醒詞體驗描寫 | 未建成 |
| 準確率百分比/任何 benchmark 數字 | 無數據 |
| 「取代人手照顧」/「唔使咁擔心阿媽」 | 產品倫理相反：目標係**連結**人，唔係代替人 |

**素材規則：** CarePanel 截圖只可用假數據；長者影像必須有尊嚴、不可扮真用戶；
如加 waitlist/聯絡表格 → 即觸發 PICS/私隱聲明需求，**先問 architect**。
